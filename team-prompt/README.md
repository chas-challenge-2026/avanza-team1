# Team Prompt - Avanza Extended Challenge 2026

**Denna mapp är Team 1's kompletta prompt för att arbeta med Avanza-projektet.**

Använd denna mapp som referens när du arbetar med AI-verktyg. Klipp in länken till denna branch i chatten, och AI:n guidar sig själv till rätt fil.

---

## 🧭 Navigation för AI & Humans

**Fråga:** "Vilken commit-format ska jag använda?"  
→ Läs **[AGENT.md](AGENT.md)** - Team standards, Git workflow, branch naming

**Fråga:** "Vad är kundproblemet och vad bygger vi?"  
→ Läs **[PROJEKTKONTEXT.md](PROJEKTKONTEXT.md)** - Kundens behov (Anna), MVP-features, tech stack

**Fråga:** "Vad måste vara klart för att det räknas som godkänt?"  
→ Läs **[DEFINITION_OF_DONE.md](DEFINITION_OF_DONE.md)** - Acceptance criteria, course objectives, timeline

**Fråga:** "Vilka tider har vi möten och när är deadlines?"  
→ Läs **[SCHEDULE.md](SCHEDULE.md)** - Team 1 master schedule, sprint planning guide

**Fråga:** "Varför gjorde vi detta arkitektur-val? Vilka beslut är tagna?"  
→ Läs **[DECISIONS.md](DECISIONS.md)** - BMAD-logg, alla beslut och resonemang

**Fråga:** "Vad hände på mötet förra veckan?"  
→ Öppna **[Mötesprotokollet](https://docs.google.com/document/d/1WD9XJBVrE49Csqz-XYiLgejlKlCA4t5sWiwoTkNiTD8/edit?tab=t.d1i0rhhuog1q)** - Levande mötes-anteckningar

## 📋 Så använder du denna prompt med AI

**Kopiera denna länk:**
```
https://github.com/chas-challenge-2026/avanza-team1/tree/docs/team-prompt/docs/team-prompt
```

**Säg till AI:n:**
```
"Använd dessa guidelines från denna länk: [länk]

Läs huvudfilen och navigera till relevanta filer för min fråga.
Min fråga är: [din fråga här]"
```

**Exempel:**
```
"Ge mig en lämplig commit-besked för vad jag just gjort.
Använd guidelines från: [länk]"
```

AI:n kommer att:
1. Läsa denna README
2. Navigera till AGENT.md för commit-format
3. Ge dig en commit-besked i rätt format
